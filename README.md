# PressIt

[![Скачать](https://img.shields.io/github/v/release/horr1ble171/PressIt?label=%D0%A1%D0%BA%D0%B0%D1%87%D0%B0%D1%82%D1%8C&color=blue)](https://github.com/horr1ble171/PressIt/releases/latest)

Утилита для автоматизации нажатий клавиш в Windows. Позволяет удерживать клавиши (режим «реального зажатия» с таймером 30 мс) и выполнять сценарии из последовательности действий с настраиваемыми задержками.

## Возможности

- **Простое удержание** — выберите клавишу, задайте длительность (секунды) или бесконечный режим. Клавиша удерживается за счёт периодической отправки `KeyDown` каждые 30 мс (как физическое зажатие).
- **Сценарии** — составьте список действий: Зажать / Отпустить / Нажать (Tap) с произвольной задержкой перед каждым. Поддерживается зацикливание (N раз или бесконечно).
- **Глобальные хоткеи** — `F6` запускает сценарий, `F7` аварийно останавливает всё (работают из любого окна, даже когда PressIt скрыто).
- **Сохранение / загрузка** сценариев в JSON.
- **Русскоязычный интерфейс**.

## Как использовать

1. Запустить `PressIt.exe`.
2. Вкладка **«Простое удержание»**: выбрать клавишу → задать время → **Старт**. Клавиша «зажата» пока не нажать **Стоп** или не истечёт таймер.
3. Вкладка **«Сценарий»**: добавить действия (задержка + тип + клавиша) → настроить зацикливание → **Запустить**. Окно скроется, клавиши пойдут в активное окно.
4. **F6** — запустить сценарий (из любого окна). **F7** — экстренная остановка, все клавиши отпускаются, окно PressIt восстанавливается.

## Формат сценария (JSON)

```json
[
  {
    "ActionType": 0,
    "Key": "W",
    "DelayMs": 1000
  },
  {
    "ActionType": 2,
    "Key": "Enter",
    "DelayMs": 500
  }
]
```

- `ActionType`: `0` = Зажать, `1` = Отпустить, `2` = Нажать (Tap)
- `Key`: любое имя из списка (W, A, S, D, Space, Ctrl, Shift, Alt, Enter, …)
- `DelayMs`: задержка **перед** этим действием в миллисекундах

## Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| F6 | Запустить сценарий (переключение на вкладку «Сценарий») |
| F7 | Аварийная остановка всего, отпускание всех клавиш |
